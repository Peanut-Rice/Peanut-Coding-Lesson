# Peanut's Coding Lesson 🎓

一个为小朋友设计的编程学习项目，包含趣味编程工具和交互式学习程序。

[English Version](README_EN.md)

## 📚 项目内容

这是一系列专为儿童设计的编程学习工具：

### 1. 📐 Logo绘画课程
**文件:** `Peanut's coding lesson.html`

- 学习Logo编程语言的基础
- 通过编写简单命令用海龟绘制图形
- 培养逻辑思维和空间想象力
- 多种主题皮肤可选（暗黑、浅色、海洋、森林、落日、糖果）

### 2. 🎹 打字练习程序
**文件:** `星光琴键：童话魔法乐章.html`

- 通过音乐和故事增强学习趣味
- 打字练习和手指灵活性训练
- 魔幻童话主题的视觉体验
- 渐进式难度设置

## 🚀 快速开始

1. 克隆或下载本仓库
2. 在网页浏览器中打开HTML文件
3. 开始学习编程！

## 📖 如何使用

### Logo绘画课
- 打开 `Peanut's coding lesson.html`
- 在编辑器中输入Logo命令
- 执行代码查看海龟绘制的图形

### 打字练习
- 打开 `星光琴键：童话魔法乐章.html`
- 按照屏幕提示进行打字练习
- 完成挑战获得反馈
