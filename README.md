# Peanut's Coding Lesson 🎓

一个为小朋友设计的编程学习项目，包含趣味编程工具和交互式学习程序。

---

English: A coding-learning project designed for children, containing fun programming tools and interactive learning programs.

## 📚 项目内容 / Project Contents

这是一系列专为儿童设计的编程学习工具：

English: A set of child-friendly coding learning tools.

### 1. 📐 Logo绘画课程 / Logo Drawing Course
**文件:** `Peanut's coding lesson.html`

- 学习Logo编程语言的基础
- 通过编写简单命令用海龟绘制图形
- 培养逻辑思维和空间想象力
- 多种主题皮肤可选（暗黑、浅色、海洋、森林、落日、糖果）

English:
- Learn the basics of the Logo programming language
- Use simple commands to draw with the turtle graphics
- Build logical thinking and spatial imagination
- Multiple theme skins available (Dark, Light, Ocean, Forest, Sunset, Candy)

### 2. 🎹 打字练习程序 / Typing Practice Program
**文件:** `星光琴键：童话魔法乐章.html`

- 通过音乐和故事增强学习趣味
- 打字练习和手指灵活性训练
- 魔幻童话主题的视觉体验
- 渐进式难度设置

English:
- Enhance learning with music and storytelling
- Typing exercises to improve finger dexterity
- Fairy-tale themed visual experience
- Progressive difficulty levels

## 🚀 快速开始 / Quick Start

1. 克隆或下载本仓库
2. 在网页浏览器中打开HTML文件
3. 开始学习编程！

English:
1. Clone or download this repository

3. Start learning to code!

## 📖 如何使用 / How to Use

### Logo绘画课 / Logo Drawing
- 打开 `Peanut's coding lesson.html`
- 在编辑器中输入Logo命令
- 执行代码查看海龟绘制的图形

English:
- Open `Peanut's coding lesson.html`
- Enter Logo commands in the editor
- Run the code to see the turtle draw graphics

### 打字练习 / Typing Practice
- 打开 `星光琴键：童话魔法乐章.html`
- 按照屏幕提示进行打字练习
- 完成挑战获得反馈

English:
- Open `星光琴键：童话魔法乐章.html`
- Follow on-screen prompts to practice typing
- Complete challenges to receive feedback
