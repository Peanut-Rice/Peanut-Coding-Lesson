Notes 使用提示

浏览器 用 Chrome 或 Edge 打开效果最好，手机上也能用。

离线 每个页面都是单个 HTML 文件，断网也能玩。

顺序 建议：先画图 → 再练打字 → 做实验 → 逛 3D 展台 → 转一转会动的画片 → 上一堂历史课 → 拆一具 3D 人体。

3D 展台 拖拽旋转、滚轮缩放；按 T 转盘、按 S 保存静帧。

会动的转筒 按「转起来」，盯着筒上的小缝看；觉得糊就慢一点，觉得卡就快一点。想画画就点底部「我要画自己的小电影」，手机上直接用手指画。

手机 竖屏最好用：转筒能直接用手指拨，画画的格子也能用手指画，画错了点「全部擦掉」。

课程配套 历史课 教师手册 · A3 长卷海报；人体课 教师手册 · 学习单。都可以打印，人体课的 3D 模型需要联网。
