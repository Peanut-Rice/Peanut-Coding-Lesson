Notes 使用提示

浏览器 用 Chrome 或 Edge 打开效果最好，手机上也能用。

离线 每个页面都是单个 HTML 文件，断网也能玩。

顺序 建议：先画图 → 再练打字 → 做实验 → 逛 3D 展台 → 上一堂历史课。

3D 展台 拖拽旋转、滚轮缩放；按 T 转盘、按 S 保存静帧。

历史课配套 教师手册 · A3 长卷海报，都可以打印。
