Notes 使用提示

浏览器 用 Chrome 或 Edge 打开效果最好，手机上也能用。

离线 每个页面都是单个 HTML 文件，断网也能玩。

顺序 建议：先画图 → 再练打字 → 做实验 → 逛 3D 展台 → 上一堂历史课 → 拆一具 3D 人体。

3D 展台 拖拽旋转、滚轮缩放；按 T 转盘、按 S 保存静帧。

手机 竖屏也能用：Logo 课的编辑器会自动换行，历史课的地图可以双指放大，课程手册也能直接打印。

奇趣阁 六件小玩具在隔壁，从标题下面的门进去。都是不用学的，没有分数；每一件都有「四件小事」，慢慢发现就好。

课程配套 历史课 教师手册 · A3 长卷海报；人体课 教师手册 · 学习单。都可以打印，人体课的 3D 模型需要联网。
